---

## 🚀 Getting Started

1. **Clone the repo**
   ```bash
   git clone https://github.com/ganesh21906/Team-31.git
   cd Team-31
   ```

2. **Run an example**
   ```bash
   python examples/01_hello_world.py
   ```

3. **Work through the exercises** – open any file in `exercises/`, read the instructions in the comments, and fill in your solution.
